# Когда переспрашивание ИИ повышает вероятность ошибки — имитационная модель

Код демонстрационной модели к тезисам доклада: Готсданкер А. «Когда переспрашивание искусственного интеллекта повышает вероятность ошибки: потребность в когнитивной завершённости и эталон правды» (конференция «Личность в культуре и образовании: психологическое сопровождение, развитие, социализация», ЮФУ, 2026).

Модель формализует теоретические следствия и не является эмпирическими данными. Коэффициенты заданы, а не оценены по выборке; выводы — условные следствия модели.

## Что моделируется

Один эпизод — один пользователь задаёт ИИ один вопрос с двумя вариантами ответа.

- Ответ ИИ верен с вероятностью `accuracy` (в тезисах 0,95).
- ИИ сопровождает ответ формулировкой «уверен» / «отчасти уверен» / «не уверен»; средняя уверенность пользователя для них 0,80 / 0,70 / 0,53 (по Steyvers et al., 2025), на шкале 1–7 это 5,8 / 5,2 / 4,2 балла (балл = 1 + 6 · доля). Восприятие зашумлено: нормальный шум со стандартным отклонением `noise` = 0,08 (≈ 0,5 балла).
- Стили: категоричный (всегда «уверен»), калиброванный: формулировка совпадает с правильностью с вероятностью 0,5 + 0,5 · `calib_quality`.
- Пользователь закрывает вопрос, если воспринимаемая уверенность достигла порога, иначе переспрашивает (не более `max_rounds` = 6 раз). Порог: `th_base + th_stakes · цена − th_nfc · nfc`, после каждого раунда снижается на `urg_base + urg_nfc · nfc`.
- Переспрашивание вскрывает ошибку с вероятностью `verify` (тогда ИИ даёт новый ответ); если не вскрыло, ИИ с вероятностью `sycophancy` меняет ответ, в том числе верный на неверный; иначе ответ устоял и уверенность растёт на 0,1 (0,6 балла).
- После закрытия вопроса возможно опровержение: верное (`cue_wrong`) или ложное (`cue_false`); готовность пересмотреть — `openness · (1 − nfc)`.
- Проверка по независимому эталону: `sycophancy=0, cue_false=0, verify=1`.

Балл опросника потребности в завершённости (шкала согласия 1–6) переводится в параметр `nfc = (балл − 1) / 5`. На шкале 1–7 порог равен `5,2 + 1,8 · цена ошибки − 0,6 · (балл − 1)`.

Уступчивость (`sycophancy`) — не свойство «ИИ вообще»: она зависит от конкретной языковой модели, задачи, формы возражения и инструкции пользователя. Поэтому в анализе устойчивости она варьируется от 0 до 0,5.

## Как воспроизвести

```bash
pip install -r requirements.txt
python reproduce_table1.py   # таблица 1 тезисов -> table1.csv
python sensitivity.py        # устойчивость вывода 1 -> sensitivity.csv
```

Генератор случайных чисел — `numpy.random.default_rng` с фиксированными seed (указаны в скриптах); 60 000 модельных пользователей на точку, стандартная ошибка доли не превышает 0,2 процентного пункта.

## English summary

`nfc_ai_model.py` simulates a user with a given need for cognitive closure who receives an AI answer (correct with a set probability), decides whether to accept it or re-ask, and may later revise it. Re-asking can expose an error but also triggers AI sycophancy. `reproduce_table1.py` and `sensitivity.py` regenerate the numbers reported in the conference abstract with fixed seeds. Parameters are set from theory, not estimated; results are conditional implications of the model.
